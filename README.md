# 角色社会链（AstrBot）

给 AI 一套**固定的**社会关系——朋友、家人、同事——让她聊天时能自然提到别人，而不是全世界只有你和她两个人。

## 解决的问题

没有这个插件时，她的对话里不会出现任何第三人。世界是扁的，像一个只为聊天存在的功能。

有了之后，她会说：

> 「我朋友小周今天又被面试挂了，笑死」
> 「我妈又来了，你说我该怎么回她」

这些话的价值不在信息量，在于**让你意识到她活在另一个有人的生活里**。

## 三个关键设计

**1. 名单固定，不许现编**

每轮对话都会把名单注入上下文，并明确写「只能提到这些人」。不这么做的话，模型每次都会顺手编一个新朋友，今天叫小周明天叫小李，反而更假。

**2. 近况每天推进一小步**

朋友不是一张快照。插件每天第一次对话时，会在后台让其中 1-2 个人的近况往前挪一点：

```
面试连挂三次 → 终于拿到一个 offer，但公司在郊区
```

只推进已有的故事线，不推翻重来；大部分人保持原样。**变化要小，像真实生活。**

**3. 从人设生成，不是随机分配**

朋友圈是按角色设定推出来的。文艺的人身边是搞乐队的，务实的身边是天天聊房子的。改了人格会自动换一套（可关闭）。

## 命令

| 命令 | 作用 |
|---|---|
| `/社会链` | 查看当前的所有人及其近况 |
| `/社会链重写` | 按当前人设重新生成整套关系 |
| `/社会链刷新` | 手动推进一次近况（不用等第二天） |

## 配置

| 面板名称 | 默认 | 说明 |
|---|---|---|
| 把社会关系注入对话 | 开 | 关掉就只是个名单生成器，没有意义 |
| 生成几个人 | 4 | 建议 3-5，太多记不住 |
| 每天自动推进近况 | 开 | 让世界是活的 |
| 生成社会关系的补充要求 | 空 | 如「必须有一个上小学的弟弟」 |
| 注入文本长度上限 | 600 | 太长挤占上下文 |
| 人设变化时自动重新生成 | 开 | 关掉后改人格不会换朋友圈 |

## 生成的字段

每个 NPC 有四项：

```
name     名字，如「小周」
relation 关系，如「大学室友」
traits   性格关键词，如「说话直，爱吐槽」
recent   当前近况，如「面试连挂三次，正在考虑转行」
```

`recent` 是最重要的字段——它必须**具体到能引发话题**。插件在生成提示里明确禁止「在上班」这种废话，要求写成「刚被调去做一个没人想接的项目」。

## 数据位置

```
data/plugin_data/astrbot_plugin_social_circle/circle.json
```

里面存了名单、生成时间、人设哈希（用于检测人格是否被改过）、最近推进日期。

## 已知限制

- **依赖 LLM**：生成和演化都要调用当前使用的 Provider。没有可用模型时退回一份内置的兜底名单，功能不至于崩，但那套名单跟人设无关。
- **不会记住对话里临时发生的事**。如果你在聊天中让小周分手了，这个变化不会被持久化，第二天的演化是从旧近况继续的。要支持这个，需要再加一个「记录朋友新闻」的工具。
- **演化质量取决于模型**。用能力弱的模型，推进出来的剧情会很干甚至重复。

## 和「她有自己的生活」的关系

这是那条线上的第一步。完整的样子还需要：

- **日程表**：她今天在忙什么，什么时候没空
- **身体状态**：她累不累、舒不舒服

三者加起来，才构成一个「她的世界不完全围着你转」的人。社会链是最容易起手的一块，因为它不需要和外部世界打交道，纯靠模型生成就能成立。
